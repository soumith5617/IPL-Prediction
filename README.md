# IPL Prediction Intelligence Pro

## Overview
A production-grade, technically validated enterprise sports analytics and machine learning platform for the **Indian Premier League (IPL)**. Delivers real-time first-innings score forecasting, second-innings chase win probability calculations, franchise rivalry analytics, verified cricketer player dossiers, and comprehensive ML model telemetry benchmarks.

## Features
- **First Innings Score Forecaster**: Predicts final 20-over totals dynamically based on current match states.
- **Second Innings Live Win Probability Engine**: Real-time chase outcome probability for batting vs. defending franchises.
- **Franchise Rivalry Matrix (Head-to-Head)**: Historical encounter records between canonical IPL franchises.
- **Player Scouting & Dossier Directory**: Verified cricketers from `Players.xlsx`.
- **ML Model Telemetry**: Transparent evaluation telemetry and model insights.
- **Audit & Prediction History**: Persistent SQLite audit logging of all generated predictions.

## Machine Learning Architecture
The system uses dual pipelines: an MLP Neural Network for score regression (First Innings) and a Gradient Boosting Classifier for win probability (Second Innings).

## Score Prediction
Predicts final scores dynamically using rolling 5-over momentum, wickets lost, overs completed, and venue scoring trends. Outputs Expected Score Range ($\pm 8$ runs) and current run rate (CRR).

## Win Probability
Real-time chase outcome probability calibrated such that $P(\text{Chasing}) + P(\text{Defending}) = 100.0\%$. Integrates Required Run Rate (RRR) pressure index and deterministic outcome guards.

## Player Analysis
Provides a directory of 566 verified cricketers with dynamically derived age, batting hand, bowling style, and dataset linkage.

## Team Analysis
Win share distributions, comparative metrics (Titles, Win Rate %, Average/Highest Scores), and match history logs for all canonical franchises.

## Model Performance
### Score Prediction Models (Holdout Evaluation on 51,255 Ball States)
- **MLP Neural Net**: MAE: 5.09 | RMSE: 8.23 | $R^2$ Score: 92.07% (Production Winner)

### Win Probability Models (Holdout Evaluation on 53,558 Chase States)
- **Gradient Boosting Classifier**: Accuracy: 96.91% | F1 Score: 97.05% | ROC-AUC: 99.54% | Log Loss: 0.1633 (Production Winner)

## Dataset
Powered by raw IPL historical datasets (`matches.csv`, `deliveries.csv`, `Players.xlsx`) covering 2008-2017 match configurations.

## Technology Stack
- **Backend**: FastAPI, Python, Scikit-Learn, SQLite, Uvicorn, Pytest
- **Frontend**: React 18, Vite, Tailwind CSS, Recharts

## Project Structure
- `backend/`: FastAPI application, database schemas, API routes, and ML inference services.
- `frontend/`: React + Vite single-page application.
- `ml/`: Model training pipelines and hyperparameter tuning scripts.
- `data/`: Source raw datasets.

## Installation
1. Clone the repository.
2. Install Python dependencies: `pip install -r requirements.txt`
3. Install Node.js dependencies: `cd frontend && npm install`

## Backend Setup
Start the backend server on `http://localhost:8000`:
```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

## Frontend Setup
Start the frontend development server on `http://localhost:5173`:
```bash
cd frontend
npm run dev
```

## Model Training
Retrain the regression and classification pipelines natively using the training scripts in the `ml/` directory. Check `run_system.py` for automated orchestration.

## Running the Application
The complete system can be run from the root using:
```bash
python run_system.py
```

## API Endpoints
Comprehensive REST API hosted under `/api`. Key domains include:
- `/api/predict/score` and `/api/predict/win`
- `/api/teams/` and `/api/players/`
- `/api/history/` and `/api/model/info`

## Testing
Run the complete backend testing suite of 90 integration/unit tests:
```bash
python -m pytest backend/tests -v
```

## Limitations
Predictions are mathematical estimates based on 2008-2017 historical data. High-variance events (weather, pitch anomalies) are not comprehensively modeled.

## Future Scope

## Disclaimer
Predictions generated by this system are mathematical estimates derived from historical IPL match data (2008–2017) and should not be considered guaranteed outcomes. T20 cricket possesses high inherent volatility influenced by in-match events such as pitch deterioration, boundary edges, fielding errors, and tactical substitutions.
